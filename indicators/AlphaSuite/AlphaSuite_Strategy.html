AlphaSuite — Multi-Indicator Strategy & Alert Engine



Short Description:

A fully configurable multi-indicator strategy & alert system combining VWAP, Supertrend, MAs, RSI/MFI/MACD/Stoch/TSI/ADX filters with built-in SL/TP/trailing and invite-only access.

Full Description:

AlphaSuite — Multi-Indicator Strategy & Alert Engine

Author: Deep Govind

License: MPL-2.0 (as stated in file header)

What it does:

This strategy combines multiple indicators (VWAP, 3× Supertrend, up to 5 configurable moving averages, RSI, MFI, MACD, Stochastic, Stoch-RSI, TSI, ADX) and allows you to build complex buy/sell rules using those building blocks.

It supports: custom session coloring, day-of-week filters, multi-timeframe inputs, auto SL/TP, percent/points/pips/ticks unit selection, trailing stop, break-even rules, alerts (signal and alert-only), and optional order execution for backtests.

Key features are highly configurable inputs for each indicator and the ability to trigger both strategy orders and alertconditions.

How to use:

1. Add the script to a chart and set the timeframes for each indicator group in the inputs panel.

2. Enable the indicators/filters you want (VWAP, Supertrend(s), MAs, RSI, etc.) and set their direction/price-overlay rules.

3. Choose SL/TP/trail type, units (% / Points / Pips / Ticks) and enable “Exit on reverse signal” if required.

4. Use the built-in alert names (“Buy Signal”, “Sell Signal”, “Buy Alert”, “Sell Alert”) when creating alerts.

Alerts & Backtests:

- Generates alertcondition for Buy/Sell signals and for Buy/Sell alerts (edge triggers). Use those exact names in TradingView alert dialog to receive webhook/push/email notifications.

- Strategy mode supports orders, backtesting and plots for entry/SL/TP/trail/break-even levels.

Limitations & disclaimers:

- This is a technical tool, not financial advice. Backtest and forward-test on your own instruments before using real capital.

- Performance depends on chart timeframe, data availability and the chosen input settings.
